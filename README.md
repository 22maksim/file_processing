# Excel N-th Minimum Number API

Простое Spring Boot-приложение, которое принимает путь к Excel-файлу и число **N**, и возвращает **N-ое минимальное число** из первого столбца файла.
Так же предлагаю добавить выбор между двумя алгоритмами **quick** и **heap**. Heap желательно использовать на большом объёме данных, 
он более стабилен и без рекурсии

## 📌 Описание задачи

1. На вход подаётся `.xlsx` файл, в котором в **первом столбце** перечислены **целые числа**.
2. Метод API принимает:
    - `filePath` — путь к локальному `.xlsx` файлу;
    - `n` — индекс минимального числа (например, `n=1` — наименьшее);
    - `algorithm` — `"quick"` (по умолчанию) или `"heap"`.
3. Алгоритм **не использует встроенную сортировку** — реализованы эффективные методы `QuickSelect` и `Max-Heap`.

## 🚀 Собрать JAR-файл через Gradle:

### В корне проекта (где находится файл build.gradle) выполни команду:

### 1. Собери jar-файл

```bash
./gradlew bootJar
````

## 2. Запуск приложения локально:

### После того как JAR-файл собран, можно запустить приложение с помощью следующей команды:

```bash
java -jar build/libs/file_processing-0.0.1-SNAPSHOT.jar
```

### 🧪 Пример запроса
```
http://localhost:8080/api/v1/excel/min-number?filePath=C%3A%5CUsers%5Cuser%5CDesktop%5Cmy-table.xlsx&n=7&algorithm=heap
```
